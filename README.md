# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:16-11-2026

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

Step 1: Creating a New Design

Open Autodesk Fusion 360 and create a new design. Select the XY plane to begin the sketch.

Step 2: Drawing the Base Profile

Draw the outer base profile using lines, circles and arcs according to the given engineering drawing.

Step 3: Applying Dimensions

Apply the required dimensions, including 100 mm and 50 mm, using the Sketch Dimension tool.

Step 4: Creating Mounting Holes

Draw the required mounting holes at their respective positions on the base profile.

Step 5: Creating the Central Circular Profile

Draw concentric circles at the centre of the base and apply the specified radius dimensions.

Step 6: Completing the Sketch

Check all the dimensions and click on Finish Sketch to complete the 2D profile.

Step 7: Extruding the Base

Select the base profile and use the Extrude command to give the required thickness to the base plate.

Step 8: Creating the Raised Portion

Select the top surface, create a new sketch and draw concentric circles. Use the Extrude command to create the raised cylindrical portion.

Step 9: Creating the Inner Hole

Select the inner circular profile and use the Extrude Cut command to create the central hole.

Step 10: Creating Supporting Ribs

Draw and extrude the supporting ribs between the central cylindrical portion and the base plate.

Step 11: Creating Additional Holes

Use the Hole or Extrude Cut command to create all the remaining required holes.

Step 12: Applying Fillet

Use the Fillet command to round the required edges and corners of the model.

Step 13: Checking the Model

Compare the completed 3D model with the given engineering drawing and make necessary corrections.

Step 14: Final Appearance

Apply a suitable appearance to the model and select the Isometric View to display the completed design.

Step 15: Saving the Design

Finally, save the completed 3D model in Autodesk Fusion 360.
